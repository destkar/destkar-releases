# Destkar

Craft, run, and manage code agents right from your mobile device.

## Download

The first release is coming soon. When it is ready, you will find the APK file under **Releases** on the right side of this page.

## How to install (Android)

1. Open **Releases** and download the latest `.apk` file.
2. Tap the downloaded file. If Android asks, allow installs from your browser or file manager.
3. Open Destkar.
